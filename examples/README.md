# Примеры использования Commutator

Эта директория содержит сложные примеры применения библиотеки Commutator для различных сценариев.

## Структура

Каждый пример находится в отдельной папке и включает:
- `README.md` - описание примера, архитектуры и использования
- `example.ts` - рабочий код примера
- `package.json` - зависимости (если нужны)

## Примеры

1. **E-commerce Order Processing** - Система обработки заказов с валидацией, расчетом стоимости и уведомлениями
2. **Game Character State Machine** - Игровая логика управления состоянием персонажа с переходами и событиями
3. **Data Pipeline with Validation** - Конвейер обработки данных с валидацией, трансформацией и агрегацией
4. **Notification System** - Система умных уведомлений с условной логикой и приоритетами
5. **Image Processing Pipeline** - Конвейер обработки изображений с фильтрами и трансформациями
6. **Authorization & Permissions** - Система авторизации и управления правами доступа
7. **Event Aggregation System** - Система агрегации событий с временными окнами и группировкой
8. **Cache Invalidation System** - Система кеширования с умной инвалидацией и зависимостями
9. **CI/CD Pipeline Workflow** - Workflow для CI/CD пайплайна с этапами и условным выполнением
10. **Analytics Calculation Engine** - Движок аналитики с вычислениями метрик и агрегацией данных
