# Cache Invalidation System

## Описание

Система кеширования с умной инвалидацией на основе зависимостей, тегов и времени жизни. Поддерживает каскадную инвалидацию, зависимые кеши и стратегии обновления.

## Архитектура

- **DataUpdated** (Event) - событие обновления данных
- **FindCacheDependencies** (Function) - поиск зависимых кешей
- **CheckCacheValidity** (PureFunction) - проверка валидности кеша
- **InvalidateCache** (Function) - инвалидация кеша
- **RefreshCache** (Function) - обновление кеша
- **UpdateDependentCaches** (Function) - обновление зависимых кешей

## Особенности

- Граф зависимостей кешей
- Каскадная инвалидация
- Стратегии обновления (lazy, eager)
- Теги для групповой инвалидации
