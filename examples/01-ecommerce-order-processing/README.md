# E-commerce Order Processing System

## Описание

Система обработки заказов в интернет-магазине с полным циклом: валидация товаров, расчет стоимости (включая скидки и налоги), проверка наличия на складе, обработка платежа и отправка уведомлений.

## Архитектура

- **OrderReceived** (Event) - событие получения нового заказа
- **ValidateProducts** (Function) - валидация товаров в заказе
- **CheckInventory** (Function) - проверка наличия товаров на складе
- **CalculatePrice** (PureFunction) - расчет базовой стоимости
- **ApplyDiscount** (PureFunction) - применение скидок
- **CalculateTax** (PureFunction) - расчет налогов
- **ProcessPayment** (Function) - обработка платежа
- **SendNotification** (Function) - отправка уведомлений клиенту

## Особенности

- Условная логика обработки (если товара нет - отправка уведомления)
- Параллельные вычисления (расчет цены, скидки, налогов)
- Обработка ошибок на разных этапах
- Динамические пины для товаров в заказе
