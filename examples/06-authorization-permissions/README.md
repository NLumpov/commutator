# Authorization & Permissions System

## Описание

Система авторизации и управления правами доступа с проверкой ролей, разрешений, ресурсов и контекстных правил. Поддерживает иерархию ролей, условные разрешения и аудит доступа.

## Архитектура

- **AccessRequest** (Event) - запрос на доступ к ресурсу
- **AuthenticateUser** (Function) - аутентификация пользователя
- **LoadUserRoles** (Function) - загрузка ролей пользователя
- **CheckPermission** (PureFunction) - проверка разрешения
- **EvaluateContextRules** (PureFunction) - оценка контекстных правил
- **CheckResourceOwnership** (Function) - проверка владения ресурсом
- **GrantAccess** (Function) - предоставление доступа
- **LogAccess** (Function) - логирование доступа

## Особенности

- Иерархия ролей и разрешений
- Контекстные правила доступа
- Проверка владения ресурсами
- Аудит всех операций доступа
