# Event Aggregation System

## Описание

Система агрегации событий с временными окнами, группировкой по различным критериям, вычислением метрик и триггерами на основе пороговых значений. Подходит для мониторинга, аналитики и обработки потоков событий.

## Архитектура

- **EventStream** (Event) - поток событий
- **TimeWindowAggregator** (Function) - агрегация по временным окнам
- **GroupEvents** (PureFunction) - группировка событий
- **CalculateMetrics** (PureFunction) - вычисление метрик
- **CheckThresholds** (Function) - проверка пороговых значений
- **TriggerAlert** (Function) - триггер алерта при превышении порога
- **StoreAggregatedData** (Function) - сохранение агрегированных данных

## Особенности

- Временные окна для агрегации
- Группировка по множественным критериям
- Вычисление различных метрик
- Пороговые значения и алерты
