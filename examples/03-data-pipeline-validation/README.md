# Data Pipeline with Validation

## Описание

Конвейер обработки данных с многоуровневой валидацией, трансформацией, фильтрацией и агрегацией. Обрабатывает потоки данных с проверкой типов, нормализацией, применением бизнес-правил и вычислением статистики.

## Архитектура

- **DataReceived** (Event) - получение нового блока данных
- **ValidateSchema** (Function) - валидация структуры данных
- **NormalizeData** (PureFunction) - нормализация данных
- **ApplyFilters** (PureFunction) - применение фильтров
- **TransformData** (PureFunction) - трансформация данных
- **AggregateData** (PureFunction) - агрегация данных
- **CalculateStatistics** (PureFunction) - вычисление статистики
- **SaveResults** (Function) - сохранение результатов

## Особенности

- Многоэтапная валидация
- Параллельная обработка разных типов данных
- Условная фильтрация
- Агрегация с группировкой
