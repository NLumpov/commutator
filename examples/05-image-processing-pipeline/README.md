# Image Processing Pipeline

## Описание

Конвейер обработки изображений с применением фильтров, трансформаций, ресайзингом и оптимизацией. Поддерживает параллельную обработку, условное применение эффектов и пакетную обработку.

## Архитектура

- **ImageUploaded** (Event) - загрузка нового изображения
- **ValidateImage** (Function) - валидация формата и размера
- **ResizeImage** (PureFunction) - изменение размера
- **ApplyFilter** (PureFunction) - применение фильтров (blur, sharpen, etc.)
- **OptimizeImage** (PureFunction) - оптимизация размера файла
- **GenerateThumbnail** (PureFunction) - генерация миниатюр
- **SaveProcessedImage** (Function) - сохранение обработанного изображения

## Особенности

- Параллельная обработка разных размеров
- Условное применение фильтров
- Пакетная обработка
- Генерация множественных форматов
