# Game Character State Machine

## Описание

Система управления состоянием игрового персонажа с переходами между состояниями (Idle, Walking, Running, Jumping, Attacking), обработкой событий (нажатия клавиш, урон, получение предметов) и условной логикой переходов.

## Архитектура

- **KeyPressed** (Event) - событие нажатия клавиши
- **DamageReceived** (Event) - событие получения урона
- **ItemCollected** (Event) - событие сбора предмета
- **StateMachine** (Function) - основная машина состояний с переходами
- **HealthCheck** (PureFunction) - проверка здоровья персонажа
- **ApplyDamage** (Function) - применение урона
- **UpdateAnimation** (Function) - обновление анимации персонажа

## Особенности

- Управление состоянием через meta
- Условные переходы между состояниями
- Обработка множественных событий
- Система здоровья с проверками
